**Inkly** یک پلتفرم انتشار و مدیریت محتوای مدرن است که با هدف ارائه‌ی تجربه‌ای سریع، امن و مقیاس‌پذیر برای نویسندگان و مدیران محتوا توسعه داده می‌شود.

این پروژه با **TypeScript، Express، PostgreSQL و Drizzle ORM** ساخته شده و شامل سیستم احراز هویت، مدیریت کاربران، مقالات، دسته‌بندی‌ها، تگ‌ها، SEO و گردش‌کار انتشار محتوا خواهد بود.

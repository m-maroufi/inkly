# 🚀 شروع سریع (Getting Started)

به مستندات رسمی **Inkly API** خوش آمدید.  
این وب‌سرویس یک RESTful API کامل، پرسرعت و امن برای پلتفرم‌های انتشار مقاله و وبلاگ‌نویسی مدرن است.

---

## 🌐 آدرس پایه سرور (Base URL)

تمام درخواست‌های ارسالی به سرور باید با پیشوند نسخه ۱ فراخوانی شوند:

```http
http://localhost:3000/api/v1
```

> [!TIP]
> در محیط پروداکشن، این آدرس به دامین اصلی سرور شما تغییر پیدا می‌کند (مثلاً: `https://api.yourdomain.com/api/v1`).

---

## 📋 هدرهای پیش‌فرض درخواست‌ها

برای تمام درخواست‌هایی که متد `POST`, `PATCH` یا `PUT` دارند، هدرهای زیر الزامی هستند:

```http
Content-Type: application/json
Accept: application/json
```

در درخواست‌های مربوط به **آپلود فایل** (مانند ماژول رسانه یا آپلود آواتار)، نوع هدر به صورت خودکار `multipart/form-data` خواهد بود.

---

## 📦 فرمت استاندارد پاسخ‌ها (Standard Response Format)

تمام پاسخ‌های ارسالی از سمت سرور دارای یک ساختار یکپارچه و قابل پیش‌بینی هستند:

### نمونه پاسخ موفق (`200 OK` یا `201 Created`):

```json
{
  "success": true,
  "message": "عملیات با موفقیت انجام شد.",
  "data": {}
}
```

### نمونه پاسخ خطا (`4xx` یا `5xx`):

```json
{
  "success": false,
  "message": "پیام خطای خوانا و مشخص",
  "errors": []
}
```

---

## ⚡ وضعیت سلامت سرور (Health Check)

برای اطمینان از بالا بودن سرور و در دسترس بودن سرویس، می‌توانید اندپوینت بررسی سلامت را صدا بزنید:

- **متد:** `GET`
- **آدرس:** `/health`
- **دسترسی:** عمومی (Public)

```bash
curl -X GET http://localhost:3000/api/v1/health
```

#### نمونه پاسخ موفق:

```json
{
  "status": "ok",
  "timestamp": "2026-11-06T12:00:00.000Z",
  "uptime": 124.5
}
```

# 👤 پروفایل و کاربران (Users)

این ماژول برای مدیریت اطلاعات فردی، ویرایش بیوگرافی و آواتار، و مشاهده پروفایل عمومی نویسندگان به همراه آمار مقالات آن‌ها طراحی شده است.  
پیشوند تمام روت‌های این ماژول: `/api/v1/users`

---

## 📑 جدول خلاصه اندپوینت‌ها

| متد     | آدرس               | دسترسی    | توضیحات                                            |
| ------- | ------------------ | --------- | -------------------------------------------------- |
| `GET`   | `/me`              | احراز شده | مشاهده مشخصات کامل حساب کاربری شخصی                |
| `PATCH` | `/me`              | احراز شده | ویرایش اطلاعات حساب و آپلود تصویر آواتار           |
| `GET`   | `/:username`       | عمومی     | دریافت صفحه پروفایل نویسنده به همراه آمار فالوورها |
| `GET`   | `/:authorId/posts` | عمومی     | دریافت مقالات منتشرشده توسط یک نویسنده خاص         |

---

## ۱. ویرایش پروفایل شخصی (Update Profile)

- **متد:** `PATCH`
- **آدرس:** `/api/v1/users/me`
- **نوع بدنه:** `multipart/form-data`
- **هدر:** `Authorization: Bearer <accessToken>`

#### فیلدهای فرم:

- `displayName`: نام نمایشی کاربر (اختیاری)
- `bio`: بیوگرافی یا درباره من (اختیاری)
- `avatar`: فایل تصویر پروفایل (اختیاری، حداکثر ۵ مگابایت)

#### نمونه پاسخ موفق (`200 OK`):

```json
{
  "success": true,
  "data": {
    "id": "u1111111-1111-1111-1111-111111111111",
    "username": "alirad",
    "displayName": "علی راد (توسعه‌دهنده وب)",
    "bio": "علاقه‌مند به معماری نرم‌افزار و نود جی‌اس",
    "avatarUrl": "http://res.cloudinary.com/.../avatar.png"
  }
}
```

---

## ۲. مشاهده پروفایل عمومی نویسنده (Public Profile)

- **متد:** `GET`
- **آدرس:** `/api/v1/users/:username`
- **دسترسی:** عمومی

#### نمونه پاسخ موفق (`200 OK`):

```json
{
  "success": true,
  "data": {
    "id": "u1111111-1111-1111-1111-111111111111",
    "username": "alirad",
    "displayName": "علی راد",
    "bio": "علاقه‌مند به معماری نرم‌افزار",
    "avatarUrl": "http://res.cloudinary.com/.../avatar.png",
    "followersCount": 42,
    "followingCount": 15,
    "postsCount": 8
  }
}
```

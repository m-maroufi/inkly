# 🔔 صندوق اعلان‌ها (Notifications)

سامانه اطلاع‌رسانی درون‌برنامه‌ای برای رویدادهای مهم مانند لایک شدن پست، دریافت کامنت جدید، دنبال شدن و وضعیت بازبینی مقالات.  
پیشوند تمام روت‌های این ماژول: `/api/v1/notifications`

---

## 📑 جدول خلاصه اندپوینت‌ها

| متد     | آدرس                    | دسترسی    | توضیحات                                                                |
| ------- | ----------------------- | --------- | ---------------------------------------------------------------------- |
| `GET`   | `/`                     | احراز شده | دریافت لیست تمام اعلان‌های کاربر جاری به همراه اطلاعات فرستنده و مقاله |
| `GET`   | `/unread-count`         | احراز شده | دریافت تعداد کل اعلان‌های خوانده‌نشده                                  |
| `PATCH` | `/:notificationId/read` | احراز شده | علامت‌گذاری یک اعلان مشخص به عنوان خوانده‌شده                          |
| `PATCH` | `/read-all`             | احراز شده | علامت‌گذاری یک‌باره تمامی اعلان‌های کاربر به عنوان خوانده‌شده          |

---

## 🏷️ انواع رویدادهای اعلان (`type`)

- `POST_LIKED`: پسندیده شدن مقاله کاربر توسط دیگری
- `COMMENT_RECEIVED`: دریافت دیدگاه جدید روی مقاله
- `COMMENT_REPLY`: پاسخ داده شدن به دیدگاه کاربر
- `NEW_FOLLOWER`: دنبال شدن توسط کاربری جدید
- `POST_SUBMITTED_FOR_REVIEW`: ارسال مقاله نویسنده جهت تایید به ادمین‌ها
- `POST_APPROVED`: تایید انتشار مقاله توسط مدیر
- `POST_REJECTED`: رد شدن مقاله توسط مدیر با ثبت دلیل

## ۱. دریافت اعلان‌های من (Get User Notifications)

- **متد:** `GET`
- **آدرس:** `/api/v1/notifications`
- **هدر:** `Authorization: Bearer <accessToken>`

#### نمونه پاسخ موفق (`200 OK`):

## ۲. تعداد اعلان‌های خوانده‌نشده (Unread Count)

- **متد:** `GET`
- **آدرس:** `/api/v1/notifications/unread-count`
- **هدر:** `Authorization: Bearer <accessToken>`

#### نمونه پاسخ موفق (`200 OK`):

```json
{
  "success": true,
  "data": {
    "unreadCount": 3
  }
}
```

# 🗂️ دسته‌بندی‌ها (Categories)

مدیریت موضوعی و ساختار درختی مقالات بر اساس دسته‌بندی‌های منحصربه‌فرد.  
پیشوند تمام روت‌های این ماژول: `/api/v1/categories`

---

## 📑 جدول خلاصه اندپوینت‌ها

| متد      | آدرس      | دسترسی    | توضیحات                                      |
| -------- | --------- | --------- | -------------------------------------------- |
| `GET`    | `/`       | عمومی     | دریافت لیست تمام دسته‌بندی‌های فعال          |
| `GET`    | `/:slug`  | عمومی     | دریافت اطلاعات دسته‌بندی بر اساس نامک (Slug) |
| `GET`    | `/id/:id` | عمومی     | دریافت اطلاعات دسته‌بندی بر اساس شناسه       |
| `POST`   | `/`       | فقط ادمین | ایجاد دسته‌بندی جدید با تولید خودکار اسلاگ   |
| `PATCH`  | `/id/:id` | فقط ادمین | ویرایش نام یا توضیحات دسته‌بندی              |
| `DELETE` | `/id/:id` | فقط ادمین | حذف دسته‌بندی از سیستم                       |

---

## ۱. ایجاد دسته‌بندی جدید (Create Category)

- **متد:** `POST`
- **آدرس:** `/api/v1/categories`
- **هدر:** `Authorization: Bearer <accessToken>` (نقش `ADMIN`)

#### بدنه درخواست (JSON):

```json
{
  "name": "توسعه وب و نود جی‌اس",
  "description": "آموزش‌های تخصصی بک‌اند و فریمورک‌های مدرن وب"
}
```

#### نمونه پاسخ موفق (`201 Created`):

```json
{
  "success": true,
  "data": {
    "id": "c1111111-1111-1111-1111-111111111111",
    "name": "توسعه وب و نود جی‌اس",
    "slug": "web-development-and-nodejs",
    "description": "آموزش‌های تخصصی بک‌اند و فریمورک‌های مدرن وب",
    "createdAt": "2026-11-06T10:00:00.000Z"
  }
}
```

## ۲. دریافت تمام دسته‌بندی‌ها (Get All Categories)

- **متد:** `GET`
- **آدرس:** `/api/v1/categories`
- **دسترسی:** عمومی

#### نمونه پاسخ موفق (`200 OK`):

```json
{
  "success": true,
  "data": [
    {
      "id": "c1111111-1111-1111-1111-111111111111",
      "name": "توسعه وب و نود جی‌اس",
      "slug": "web-development-and-nodejs",
      "description": "آموزش‌های تخصصی بک‌اند"
    }
  ]
}
```

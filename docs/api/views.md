# 👁️ ثبت بازدید مقالات (Views)

موتور ثبت بازدید هوشمند و ضد اسپم با استفاده از کش دو لایه ردیس (Redis Debounce Engine).  
پیشوند تمام روت‌های این ماژول: `/api/v1/views`

---

## 🛡️ مکانیزم ضد اسپم (Anti-Spam Architecture)

برای جلوگیری از افزایش کاذب بازدید با رفرش مکرر صفحه:

1. **کاربران لاگین‌شده:** کلید ردیس بر اساس شناسه کاربری (`userId`) ست می‌شود.
2. **کاربران مهمان:** کلید ردیس بر اساس آدرس `IP` ست می‌شود.
3. **همگام‌سازی کاربر و IP:** اگر کاربری به عنوان مهمان وارد شود و سپس لاگین کند، بازدید دوم در بازه زمانی کش ۱ ساعته ثبت نخواهد شد.

---

## 📑 جدول خلاصه اندپوینت‌ها

| متد    | آدرس            | دسترسی                | توضیحات                                  |
| ------ | --------------- | --------------------- | ---------------------------------------- |
| `POST` | `/post/:postId` | عمومی / احراز اختیاری | ثبت بازدید جدید برای مقاله با کنترل ردیس |
| `GET`  | `/post/:postId` | عمومی                 | دریافت تعداد کل دفعات مشاهده مقاله       |

---

## ۱. ثبت بازدید مقاله (Record Post View)

- **متد:** `POST`
- **آدرس:** `/api/v1/views/post/:postId`
- **هدر:** اختیاری (در صورت ارسال `Authorization: Bearer` شناسه کاربر لاگین‌شده ثبت می‌شود)

#### نمونه پاسخ موفق (هنگام ثبت بازدید نو):

```json
{
  "success": true,
  "message": "View recorded successfully.",
  "data": {
    "recorded": true
  }
}
```

#### نمونه پاسخ موفق (هنگامی که در ۱ ساعت اخیر قبلاً دیده شده):

```json
{
  "success": true,
  "message": "View skipped due to debounce.",
  "data": {
    "recorded": false
  }
}
```

---

## ۲. دریافت آمار کل بازدیدهای مقاله (Get Views Count)

- **متد:** `GET`
- **آدرس:** `/api/v1/views/post/:postId`
- **دسترسی:** عمومی

#### نمونه پاسخ موفق (`200 OK`):

```json
{
  "success": true,
  "data": {
    "totalViews": 458
  }
}
```

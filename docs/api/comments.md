# 💬 دیدگاه‌ها و نظرات (Comments)

سیستم نظرات درختی و سلسله‌مراتبی (Threaded / Nested Comments) با امکان پاسخ به نظرات دیگران (Replies).  
پیشوند تمام روت‌های این ماژول: `/api/v1/comments`

---

## 📑 جدول خلاصه اندپوینت‌ها

| متد      | آدرس            | دسترسی              | توضیحات                                          |
| -------- | --------------- | ------------------- | ------------------------------------------------ |
| `GET`    | `/post/:postId` | عمومی               | دریافت درخت کامل نظرات یک مقاله به همراه پاسخ‌ها |
| `POST`   | `/post/:postId` | احراز شده           | ثبت دیدگاه جدید (نظر اصلی یا پاسخ با `parentId`) |
| `PATCH`  | `/:commentId`   | نویسنده نظر / ادمین | ویرایش متن دیدگاه                                |
| `DELETE` | `/:commentId`   | نویسنده نظر / ادمین | حذف دیدگاه از سیستم                              |

---

## ۱. ثبت نظر جدید یا پاسخ (Create Comment)

- **متد:** `POST`
- **آدرس:** `/api/v1/comments/post/:postId`
- **هدر:** `Authorization: Bearer <accessToken>`

> [!TIP]
> برای ثبت پاسخ به یک نظر، کافیست شناسه نظر والد را در فیلد `parentId` بفرستید. در غیر این صورت فیلد `parentId` را نفرستید یا `null` بگذارید.

#### بدنه درخواست (JSON):

```json
{
  "content": "مقاله فوق‌العاده‌ای بود! ممنون از توضیحات عالی در رابطه با Express 5.",
  "parentId": null
}
```

#### نمونه پاسخ موفق (`201 Created`):

```json
{
  "success": true,
  "data": {
    "id": "cm111111-1111-1111-1111-111111111111",
    "postId": "p1111111-1111-1111-1111-111111111111",
    "userId": "u1111111-1111-1111-1111-111111111111",
    "content": "مقاله فوق‌العاده‌ای بود! ممنون از توضیحات عالی در رابطه با Express 5.",
    "parentId": null,
    "createdAt": "2026-11-06T11:00:00.000Z"
  }
}
```

## ۲. دریافت نظرات درختی مقاله (Get Post Comments)

- **متد:** `GET`
- **آدرس:** `/api/v1/comments/post/:postId`
- **دسترسی:** عمومی

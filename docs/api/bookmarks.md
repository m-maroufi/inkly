# 🔖 نشان‌کردن مقالات (Bookmarks)

امکان نشان‌کردن (Bookmark) مقالات برای مطالعه در آینده و دسترسی به لیست شخصی نشان‌شده‌ها.  
پیشوند تمام روت‌های این ماژول: `/api/v1/bookmarks`

---

## 📑 جدول خلاصه اندپوینت‌ها

| متد    | آدرس              | دسترسی    | توضیحات                                                       |
| ------ | ----------------- | --------- | ------------------------------------------------------------- |
| `POST` | `/:postId`        | احراز شده | افزودن به بوکمارک یا حذف از بوکمارک (Toggle)                  |
| `GET`  | `/:postId/status` | احراز شده | استعلام اینکه آیا این مقاله در لیست نشان‌شده‌های من است یا نه |
| `GET`  | `/me`             | احراز شده | دریافت لیست کامل مقالات نشان‌شده کاربر جاری                   |

---

## ۱. تغییر وضعیت نشان‌کردن (Toggle Bookmark)

- **متد:** `POST`
- **آدرس:** `/api/v1/bookmarks/:postId`
- **هدر:** `Authorization: Bearer <accessToken>`

#### نمونه پاسخ موفق (افزوده شدن به بوکمارک):

```json
{
  "success": true,
  "data": {
    "bookmarked": true,
    "message": "Post bookmarked successfully."
  }
}
```

---

## ۲. دریافت لیست نشان‌شده‌های من (Get My Bookmarks)

- **متد:** `GET`
- **آدرس:** `/api/v1/bookmarks/me`
- **هدر:** `Authorization: Bearer <accessToken>`

#### نمونه پاسخ موفق (`200 OK`):

```json
{
  "success": true,
  "data": [
    {
      "id": "p1111111-1111-1111-1111-111111111111",
      "title": "راهنمای جامع معماری تمیز در نود جی‌اس",
      "slug": "clean-architecture-guide-in-nodejs",
      "excerpt": "بررسی لایه‌بندی در پروژه‌های مدرن وب",
      "bookmarkedAt": "2026-11-06T11:30:00.000Z"
    }
  ]
}
```

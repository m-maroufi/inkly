# 📝 پست‌ها و مقالات (Posts)

قلب تپنده اینکلی؛ مدیریت کامل چرخه حیات مقالات، ورک‌فلو بازبینی ادمین و انتشار مقالات همراه با سئو و کاور.  
پیشوند تمام روت‌های این ماژول: `/api/v1/posts`

---

## 🔄 چرخه انتشار مقالات (Workflow)

```text
DRAFT (پیش‌نویس)
  ↓ (ارسال توسط نویسنده)
PENDING_REVIEW (در انتظار تایید مدیر)
  ↓ (تایید توسط ادمین)
APPROVED (تایید شده)
  ↓ (انتشار نهایی)
PUBLISHED (منتشر شده عمومی)
```

---

## 📑 جدول خلاصه اندپوینت‌ها

| متد      | آدرس                     | دسترسی          | توضیحات                                                 |
| -------- | ------------------------ | --------------- | ------------------------------------------------------- |
| `GET`    | `/`                      | عمومی           | دریافت لیست تمام مقالات منتشر شده                       |
| `GET`    | `/:slug`                 | عمومی           | مشاهده صفحه کامل مقاله همراه با نویسنده، تگ‌ها و آمار   |
| `POST`   | `/`                      | نویسنده / ادمین | نگارش مقاله جدید (پیش‌نویس اولیه) و آپلود کاور          |
| `PATCH`  | `/:postId`               | مالک / ادمین    | ویرایش عنوان، محتوا، دسته‌بندی یا کاور مقاله            |
| `DELETE` | `/:postId`               | مالک / ادمین    | حذف مقاله از سیستم                                      |
| `POST`   | `/:postId/submit-review` | مالک مقاله      | ارسال مقاله برای بازبینی ادمین                          |
| `POST`   | `/:postId/review`        | فقط ادمین       | تایید (`APPROVED`) یا رد (`REJECTED`) مقاله با ثبت دلیل |
| `POST`   | `/:postId/publish`       | مالک / ادمین    | انتشار نهایی مقاله تایید شده در وبلاگ                   |
| `GET`    | `/admin/pending-reviews` | فقط ادمین       | مشاهده لیست مقالات منتظر بازبینی                        |

## ۱. ایجاد مقاله جدید (Create Post)

- **متد:** `POST`
- **آدرس:** `/api/v1/posts`
- **نوع بدنه:** `multipart/form-data`
- **هدر:** `Authorization: Bearer <accessToken>`

#### فیلدهای فرم:

- `title`: عنوان مقاله (اجباری)
- `content`: محتوای متنی مقاله (اجباری)
- `categoryId`: شناسه دسته‌بندی (اجباری)
- `excerpt`: چکیده مقاله (اختیاری)
- `tagIds`: آرایه‌ای از شناسه‌های تگ (اختیاری)
- `coverImage`: فایل تصویر کاور (اختیاری)

#### نمونه پاسخ موفق (`201 Created`):

```json
{
  "success": true,
  "data": {
    "id": "p1111111-1111-1111-1111-111111111111",
    "title": "راهنمای جامع معماری تمیز در نود جی‌اس",
    "slug": "clean-architecture-guide-in-nodejs",
    "status": "DRAFT",
    "coverImageUrl": "http://res.cloudinary.com/.../cover.png"
  }
}
```

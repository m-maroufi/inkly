# 🏷️ برچسب‌ها (Tags)

برچسب‌گذاری مقالات با ارتباط چندبه‌چند (`many-to-many`) جهت فیلتر و کشف آسان‌تر محتوا.  
پیشوند تمام روت‌های این ماژول: `/api/v1/tags`

---

## 📑 جدول خلاصه اندپوینت‌ها

| متد      | آدرس      | دسترسی          | توضیحات                                  |
| -------- | --------- | --------------- | ---------------------------------------- |
| `GET`    | `/`       | عمومی           | دریافت تمام برچسب‌های موجود              |
| `GET`    | `/:slug`  | عمومی           | دریافت مشخصات برچسب بر اساس اسلاگ        |
| `GET`    | `/id/:id` | عمومی           | دریافت مشخصات برچسب با شناسه             |
| `POST`   | `/`       | نویسنده / ادمین | تعریف برچسب جدید (با تولید خودکار اسلاگ) |
| `PATCH`  | `/:id`    | فقط ادمین       | ویرایش نام برچسب                         |
| `DELETE` | `/:id`    | فقط ادمین       | حذف برچسب از سیستم                       |

---

## ۱. تعریف برچسب جدید (Create Tag)

- **متد:** `POST`
- **آدرس:** `/api/v1/tags`
- **هدر:** `Authorization: Bearer <accessToken>`

#### بدنه درخواست (JSON):

```json
{
  "name": "اکسپرس ۵"
}
```

#### نمونه پاسخ موفق (`201 Created`):

```json
{
  "success": true,
  "data": {
    "id": "t1111111-1111-1111-1111-111111111111",
    "name": "اکسپرس ۵",
    "slug": "express-5"
  }
}
```
